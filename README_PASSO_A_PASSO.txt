PUBLICAÇÃO NO RENDER (quando os arquivos estiverem no GitHub):
1. No Render, escolha New + e depois Static Site.
2. Conecte o repositório do site.
3. Em Build Command, deixe vazio.
4. Em Publish Directory, use um ponto: .
5. Clique em Create Static Site.
6. Depois de publicado, copie o endereço do site.
7. Na Kiwify, substitua a página de vendas do Instagram pelo endereço do site.
